# Clever Garcia · Consórcio Gazin

Página de apresentação e credenciamento de representantes do Consórcio Gazin no Nordeste, com contato direto com Clever Garcia.

## Conteúdo

- Site responsivo em HTML, CSS e JavaScript.
- Catálogo de sete segmentos com Splide.
- Ícones Lucide.
- Formulário que prepara uma mensagem no WhatsApp; nenhum cadastro é armazenado no site.
- Apresentação em PDF para download.

## Executar localmente

```sh
python -m http.server 5176 --directory dist
```

Acesse http://localhost:5176. Não é necessário instalar dependências ou executar build.

## Vercel

O arquivo `vercel.json` configura a publicação estática da pasta `dist`. A branch de produção é `main`.
